# Documentación del Proyecto - Scene One

Esta carpeta centraliza toda la documentación técnica, académica y de ingeniería de software que respalda el desarrollo de la aplicación web.

## Propósito de la Carpeta
A diferencia de las carpetas de código, este directorio almacena la "evidencia" del proceso de diseño y análisis. Sirve como referencia para entender las decisiones de negocio, los flujos de trabajo y los requerimientos del cliente.

## Entregables y Archivos (Próximamente)
A medida que avance el proyecto, aquí se irán almacenando:
* **Entrevistas y Levantamiento:** Guiones de preguntas, minutas de reuniones y requerimientos obtenidos del cliente (Scene One).
* **Modelado de Procesos:** Diagramas BPMN que explican el flujo de ventas, gestión de inventario y atención al cliente.
* **Informes Académicos:** Documentos en formato PDF con la arquitectura del sistema, manuales de usuario y bitácoras de avance del equipo.
* **Historias de Usuario:** Detalle funcional de lo que el sistema debe hacer desde la perspectiva del cliente y del administrador.

> **💡 Nota de Organización:** 
> Todos los documentos finales deben subirse preferentemente en formato PDF para evitar problemas de compatibilidad al revisarlos, y los nombres de los archivos deben ser claros (ej: `Informe_Final_SceneOne.pdf`).
