# Recursos Estáticos y Multimedia - Scene One

Esta carpeta está destinada a almacenar todos los archivos estáticos, recursos visuales y documentos de diseño que componen la identidad gráfica de la aplicación.

## Propósito de la Carpeta
Mantener el repositorio ordenado separando el código fuente de los archivos pesados o multimedia. Aquí se centraliza todo lo visual para que la aplicación en Streamlit pueda cargarlo rápidamente.

## Contenido del Directorio
* **Logotipos corporativos:** Versiones del logo de Scene One (PNG, SVG, etc.) para la interfaz.
* **Prototipos (Mockups):** Exportaciones o enlaces a los diseños preliminares trabajados en Figma.
* **Imágenes de prueba:** Fotografías de los productos (poleras, polerones) usadas antes de conectar la base de datos a un Storage en la nube.
* **Íconos y tipografías:** Recursos extra que se inyectan en el frontend mediante CSS.

> **💡 Buenas Prácticas del Proyecto:** 
> Toda imagen que se suba a esta carpeta debe estar optimizada y comprimida para no sobrecargar el repositorio de GitHub ni afectar el tiempo de carga de la página.
